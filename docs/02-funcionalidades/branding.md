# Branding & Identidade Visual

## O que é
Identidade "Escalafut" — sem qualquer traço de Lovable no produto final.

## O que ele faz
- Paleta: verde escuro (primary) + dourado (accent).
- Tipografia: fonte heading esportiva + sans padrão para corpo.
- Metadados: `<title>`, `og:*`, `twitter:*` com nome/descrição do Escalafut.
- Favicon próprio.
- Nenhuma referência textual/visual a Lovable no `index.html`, `README.md`, CSS ou assets.

## Como funciona
- Tokens em `src/index.css` + `tailwind.config.ts`.
- Head em `index.html`.
- README na raiz descreve o Escalafut.

## Dependências
- Nenhuma funcional. Base de todas as telas.

Em produção.
